Automação de Relatório de Vendas com n8n

📋 Visão Geral

Este projeto automatiza um processo manual de criação de relatórios de vendas utilizando o n8n.
O workflow obtém dados de encomendas através de uma API, separa as encomendas de acordo com o seu estado, armazena as encomendas em processamento numa Data Table e prepara a informação para análise e relatórios.
🚀 Funcionalidades

* Obter dados de vendas através de uma API
* Filtrar encomendas por estado (Processing / Reserved)
* Armazenar encomendas em processamento numa Data Table
* Preparar dados para relatórios automáticos
* Reduzir trabalho manual e erros humanos
🛠 Tecnologias Utilizadas

* n8n
* API REST
* Data Tables
* JSON
💡 Competências Demonstradas

* Automação de Workflows
* Integração com APIs
* Processamento de Dados
* Lógica Condicional
* Mapeamento de Dados
* Desenvolvimento Low-Code
